# PCOL 斯诺克增强脚本

在原版 [PCOL](http://www.heyzxz.me/pcol/) 上运行的 Tampermonkey 用户脚本，支持本地“人格分裂”双人局和斯诺克规则改进。

## 安装

Chrome 安装 Tampermonkey 后，打开 [用户脚本安装链接](https://raw.githubusercontent.com/1034701377-web/pcol-snooker-enhancements/main/outputs/pcol-rules-patch.user.js)，在油猴安装页确认安装或更新。刷新游戏页面后生效。

首页左下角点击“开始双人局”，由同一人轮流控制两名玩家。原版 AI 对战入口仍可使用；点击原版 PRACTICE 或浮窗“练球”可选择两种练习模式。

旧 Gist 安装链接会提供迁移更新；更新到本版本后，后续自动更新从这个仓库获取。

## 已实现

- 犯规后接手、让犯规者从现位置重打，以及“犯规与空杆”后的整桌复位。
- 白球落袋／离台后的复位与 D 区手中球处理。
- 自由球判定、提名、计分和复位。
- 跳球犯规判定及合法例外。
- 彩球目标在出杆前确定：意图明确时自动识别，否则要求手动指定。
- 贴球提示、合法打离豁免、出杆推动相贴球的判罚；贴彩球时要求明确声明目标。
- 粉球复位时，所有彩球点不可用则优先沿中线向黑球端找最近的不相贴位置，该方向无位置才向底库找；适用于 AI 对局、双人局和标准练习。自定义自由练习仍不自动复位彩球。
- 换方时，落后方的分差减去台面剩余最高得分达到 20 分，可选择认输。
- 浮窗可拖动并记忆位置，双击拖动柄复位；观看回放时隐藏。
- 单杆首次达到 100 分时播放暖金与台呢绿的破百庆祝，自动收起，不拦截操作；支持减少动态效果。
- 自定义摆球：直接在原版三维球台操作，竖向球盘只显示球体，绿色圆圈表示可放，橙色表示不可放，点击确定。使用一套标准球组（1 白、最多 15 红、每种彩球各 1），禁止重叠、越库和袋口内摆球。
- 正常球形练习：一名单人玩家按斯诺克规则持续练习，失误或犯规后继续由自己击球。
- 两种练习每杆停球后均可“复位重打”，恢复整桌球位、目标球、分数及单杆统计；最后一颗黑球也能重打。

## 练球

直接点击原版 PRACTICE 入口选择练习模式。自定义模式在原三维球台旁显示球盘，不切换俯视画面。点击球体即可进入摆球，在绿圈位置点击放球；橙圈位置不能放。选择已有彩球会移动同一颗球，红球可连续添加。拖动桌面或按 A/D 沿用原版调整视角的操作。

按 W 确认摆球并进入瞄准，两块控制台同时隐藏；每杆停球后自动显示，可直接再次点球体编辑，无需点“摆球”。站起后也可继续编辑。“取消本次编辑”或 Esc 恢复本次编辑前的球形；确认修改后的球形会清零本次练习统计。普通比赛的白球手中球仍限定在原版 D 区。

控制台采用深绿与暖金配色，界面只保留球体和必要操作。竖向球盘宽 104px，“清空目标球”和“标准球形”各占一行。拖动“自由摆球”标题或“自由练习”文字可移动对应控制台，位置自动记忆；双击恢复默认位置。球名和红球数量可在悬停提示中查看。

自定义模式为自由击球：不限制先碰球，目标球进袋后不自动取回，不计算斯诺克单杆分。需要按规则计分时选择“正常球形”。两种模式的“复位重打”只撤销最近完成的一杆，出杆和观看回放期间不可用；原版暂停菜单中的重新开始会重摆本次自定义球形或正常开局球形。

版本标签 `v0.1.6` 保留破百庆祝版本；`v0.2.0` 加入两种练习和复位重打；`v0.2.1` 将自定义摆球改为原生三维操作；`v0.2.2` 精简控制台并自动切换摆球与击球界面。

## 判罚边界

规则参考 [WPBSA 2024–25](https://wpbsa.com/wp-content/uploads/2198_WPBSA-Rulebook-2024-25.pdf)。本脚本面向 PCOL `0.1.0.03152018`。

遮挡下的是否尽力解球、手中球在整个 D 区的自由球证明，以及边界腾空轨迹仍需人工裁判确认。原游戏的同分重摆黑球等未被本脚本完整接管。原版 AI 仍使用自己的算法，不能自动处理所有新增裁判选择。

## 开发

只需 Node.js，无第三方依赖：

```sh
npm run build
npm test
```

`npm run check` 一次完成构建、脚本语法检查和测试。版本号在 `package.json` 修改，再重新构建。

- `src/rules-core.js`：纯规则与几何计算。
- `src/integration.js`：游戏接入、控制器和界面；版本占位符由构建替换。
- `src/celebration.js`：破百庆祝动画；`src/practice-editor.js`：摆球界面与几何校验。
- `outputs/pcol-rules-patch.user.js`：完整可安装脚本，由构建生成。
- `test/`：规则和原版模型交互的回归测试；`fixtures/pcol-model.js` 是从原版游戏提取的最小模型测试资源，不会打包到用户脚本。

原游戏由 [heyzxz](https://github.com/heyzxz/all-about-pcol) 制作。本项目提供浏览器侧补丁，不包含原游戏的完整资源包，也没有联机服务器或外部 AI 服务。
